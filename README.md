# Shan — AI/ML Portfolio

Responsive personal portfolio for Shan, BS Artificial Intelligence student at Riphah International University.

## Quick start

Dependency-free static website:

```bash
python -m http.server 8000
```

Visit `http://localhost:8000`.

## Structure

- `index.html` — site content and sections
- `styles.css` — themes, layout and animations
- `script.js` — interactive behavior and project data
- `assets/` — pictures, favicon and CV
- `downloads/` — optional packaged source snapshot
- `vercel.json` — Vercel configuration

## Deployment

Supports static hosting on Vercel, GitHub Pages, or conventional web hosting. Confirm deployment status separately; repository presence alone does not confirm a live website.

## Editing

Update content and social links in `index.html`, project entries in `script.js`, and styling in `styles.css`.
