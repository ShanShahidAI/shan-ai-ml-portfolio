# Shan — AI / ML & Software Portfolio

Personal portfolio of **Shan**, BS Artificial Intelligence student at Riphah International University, Islamabad.

**Live:** https://shan-ai-ml-portfolio.vercel.app/  
**GitHub:** https://github.com/ShanShahidAI  
**LinkedIn:** https://www.linkedin.com/in/shan-shahid-ai

## What is included

- Responsive, accessible hero and authentic supplied portrait image
- 15 source-grounded project / coursework entries (see `projects.json`)
- Category filters, keyword search and interactive detailed case studies
- GitHub source references for **every** case-study entry
- Real repo-generated screenshots / figures where available; source-based illustrations are **explicitly labeled** elsewhere
- Honest project descriptions, team attribution, historical test contexts and caveats
- Real course-completion certificates supplied during profile setup
- PDF CV and editable DOCX CV
- Email, phone, WhatsApp and LinkedIn contact paths
- Light and dark themes and reduced-motion support

## Quick start

Static site; no Node toolchain or dependencies necessary.

```bash
python -m http.server 8000
```

Visit `http://localhost:8000` (opening `index.html` as a `file://` document will not fetch `projects.json` in browsers with local-file restrictions).

## Project sources and authenticity

- Content and outcomes come from public GitHub repositories, their README documents and saved evaluation reports available in November 2026.
- Linked screenshot URLs point to **actual source repository output files** (when those files exist).
- Code-study illustration images under `assets/preview-*.webp` are intentionally **not represented as application screenshots**.
- Historical test reports are labelled historical and were not newly executed while constructing this portfolio.
- Educational model performance is not presented as validated real-world accuracy.
- The site intentionally does not claim professional work experience or independently authored group code.

## Technology

Vanilla HTML/CSS/JavaScript. No third-party JS dependencies, backend, tracking, or client secrets.

## Editing

- Projects and per-project links: `projects.json`.

Vercel project: `shan-ai-ml-portfolio`. The application is static and can also run on GitHub Pages or simple hosting. Contact form invokes the visitor's mail application, rather than implying backend delivery.
